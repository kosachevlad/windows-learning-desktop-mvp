# Етап 2 — навчальна файлова система

## Що реалізовано

Незалежний від Android домен у `app/src/main/java/ua/school/windowsdesktop/domain/`:

- Папки, текстові документи та байти малюнків із незмінними ідентифікаторами й метаданими.
- Створення, читання, запис, перейменування, копіювання/вставлення піддерева, Кошик і відновлення.
- Знімки стану, захищені від зовнішніх змін. Невдала операція не публікує частковий результат.
- Стабільні коди помилок для подальших повідомлень українською та англійською.

Це стан **у пам'яті процесу**. Room, збереження на диску та відновлення після перезапуску ще не реалізовані. Поточний екран Android залишається статичним. На телефоні файлові операції цього етапу ще не доступні; їх перевіряємо JVM-тестами на комп'ютері без емулятора.

## Правила

- Корінь має ID `root`; його не можна перейменувати, скопіювати чи видалити.
- Імена нормалізуються до Unicode NFC; порівняння сусідніх імен нечутливе до регістру. Однакові імена в різних папках дозволені.
- Заборонені порожні імена, керівні символи 0–31, `\ / : * ? " < > |`, кінцева крапка/пробіл, базові службові імена CON/PRN/AUX/NUL/COM1–9/LPT1–9. Ліміт — 255 одиниць UTF-16. Це визначені правила навчального сховища, не повна реалізація NTFS.
- Для тексту/малюнка без крапки додається `.txt`/`.png`. Якщо вказано інше розширення, операція повертає INVALID_EXTENSION. Перейменування не змінює тип документа.
- Розмір тексту — кількість UTF-8 байтів, малюнка — кількість переданих байтів; папка має розмір 0 без рекурсивного підрахунку. Домен не перевіряє PNG-кодек — це відповідальність майбутнього Paint/сховища.
- Буфер обміну належить застосунку. Він зберігає ID джерела, тому вставлення бере його актуальні назву й вміст. Видалене джерело не можна вставити до відновлення.
- Вставлення зберігає ім'я, якщо воно вільне. При конфлікті: `Історія (копія).txt`, `Історія (копія 2).txt`. Параметр copyLabel дозволяє майбутньому UI передати `copy` для English.
- Копія папки містить лише активні об'єкти, отримує нові ID, а редагування копії не змінює оригінал. Копіювання в себе чи власну вкладену папку заборонене.
- Видалення папки приховує її піддерево, зберігаючи зв'язки та вміст. Кошик показує явно видалені об'єкти. Раніше окремо видалений файл залишається в Кошику після відновлення папки.
- Відновлення повертає попередній батьківський каталог або корінь, якщо каталог недоступний. Конфлікт імені не перезаписує інший файл: можна повторити restore з newName.
- Операції серіалізовані, а snapshot доступний як незмінний знімок. Атомарність у пам'яті не є гарантією збереження при закритті застосунку.

## Як запустити тести

Перевірка 2026-09-13: **22 тести, 0 failures, 0 errors, 0 skipped**. Спільний запуск `testDebugUnitTest assembleDebug assembleDebugAndroidTest` завершився BUILD SUCCESSFUL (71 задача: 7 виконано, 64 актуальні). APK UI-тестів зібрано, instrumentation на пристрої під час цього етапу не запускався.

У PowerShell, з кореня репозиторію:

```powershell
. ./scripts/Use-LocalToolchain.ps1
./gradlew.bat --no-daemon testDebugUnitTest --tests '*FileOperationsTest'
```

Очікуйте BUILD SUCCESSFUL. Перший запуск може завантажувати залежності. У разі UP-TO-DATE результати попереднього запуску актуальні; для примусового повторення додайте `--rerun-tasks`.

Відкрити HTML-звіт:

```powershell
Start-Process ./app/build/reports/tests/testDebugUnitTest/index.html
```

У звіті всі тести мають бути зеленими, failures = 0, ignored = 0. Перевірка збірки застосунку та APK UI-тестів:

```powershell
./gradlew.bat --no-daemon assembleDebug assembleDebugAndroidTest
```

Перевірку запуску на пристрої описано в README. Вона не замінює доменні тести цього етапу.
