# Етап 4 — перший інтерактивний сценарій

Перевірено 2026-09-14: **42 JVM-тести пройдено, 0 failures/errors/skipped**; `assembleDebug` і `assembleDebugAndroidTest` завершилися успішно. APK перевірено `apksigner` (debug-підпис v2). Два UI-тести скомпільовані, але не запущені через відсутність підключеного пристрою.

Перша UI-версія підключає Compose до реального `LearningFileRepository`. На робочому столі працюють «Цей ПК», «Мої файли» та «Блокнот». Провідник показує чотири колонки, відкриває вкладені папки й текстові документи, створює нову папку або `.txt`. Блокнот читає та зберігає UTF-8 текст; незбережений документ позначається `*`, а закриття показує «Зберегти зміни?».

На цьому кроці ще немає контекстних меню, перейменування, копіювання, видалення, Кошика, сортування, зміни ширини колонок, Save As, англійської мови й Paint. Іконки тимчасові відповідно до домовленості.

Виправлення після ручної перевірки: запуск Блокнота з робочого столу відкриває чернетку в пам’яті. Якщо її закрити без редагування та явного збереження, порожній файл не створюється. Натискання «Зберегти» створює файл навіть із порожнім текстом, бо це навмисна дія користувача.

## Ручна перевірка на Android

Встановити новий APK поверх попереднього:

```powershell
adb install -r .\app\build\outputs\apk\debug\app-debug.apk
```

Якщо встановлюєш файл вручну, відкрий `windows-learning-desktop-stage-4.apk`. Не видаляй стару версію перед оновленням, якщо хочеш зберегти її app data.

1. Відкрий застосунок і натисни «Мої файли». Має відкритися порожній Провідник із колонками «Ім’я», «Дата змінення», «Тип», «Розмір».
2. Натисни «Нова папка», введи `Урок 1`, підтвердь. Натисни папку, потім «Новий текстовий документ», введи `Моя історія` — розширення `.txt` додасться автоматично.
3. Натисни `Моя історія.txt`, введи `Привіт! Це мій перший файл.`. У заголовку має з’явитися `*`.
4. Натисни «Зберегти». `*` має зникнути. На фізичній клавіатурі також перевір Ctrl+S.
5. Зміни текст і натисни Android Back або `×`. Має з’явитися «Зберегти зміни?». Перевір окремо «Скасувати», «Не зберігати» та «Зберегти».
6. Збережи фінальний текст, повернися на робочий стіл і повністю закрий застосунок через список останніх програм. Відкрий його знову, зайди `Мої файли → Урок 1 → Моя історія.txt`. Текст має зберегтися.
7. Створи в тій самій папці документ із тим самим ім’ям. Має з’явитися повідомлення про конфлікт, а перший файл і його текст не повинні змінитися.

Через Android Settings → Apps → Windows Learning Desktop → Storage → Clear storage можна очистити навчальну файлову систему для повторення сценарію. Це видалить усі створені в застосунку навчальні файли.
